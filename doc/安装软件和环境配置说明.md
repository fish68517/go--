# 安装软件和环境配置说明

本文档按 Windows 本机运行本项目编写。项目目录：

```text
E:\项目\Go-区块链\中药房中药材溯源系统
```

## 一、需要安装的软件

| 软件 | 用途 | 建议版本 | 下载地址 |
| --- | --- | --- | --- |
| Go | 运行 `code/go` 后端 | `go.mod` 要求 `1.26.1`，可安装同主版本更新补丁 `1.26.x` | [Go 官方下载](https://go.dev/dl/) |
| MySQL Server | 后端数据库 | MySQL 8.0.x，SQL 文件来源版本为 8.0.32 | [MySQL Installer 官方下载](https://dev.mysql.com/downloads/installer/) |
| Node.js | 运行 `code/vue` 和 `code/dapingzhanshi` | Node.js LTS | [Node.js 官方下载](https://nodejs.org/en/download) |
| Git | 拉代码、检查版本、提交代码 | Windows 版 Git | [Git for Windows](https://git-scm.com/install/windows) |
| MySQL Workbench 或 Navicat | 可选，用于导入 SQL | 与 MySQL 8.0 兼容即可 | MySQL Installer 可一起安装 Workbench |

说明：

- 后端 `code/go/go.mod` 写的是 `go 1.26.1`，本机 Go 版本必须不低于 `1.26.1`。如果 Go 官方下载页显示 `1.26.3` 等同主版本补丁版，可以直接安装。
- `code/dapingzhanshi` 是旧版 Vue 2 + Vue CLI 4 项目，`code/vue` 是 Vue 3 + Vite 6 项目。建议优先安装 Node.js LTS；如果大屏运行时报 OpenSSL 相关错误，见本文最后的排错。

## 二、安装 Go

1. 打开 [Go 官方下载页](https://go.dev/dl/)。
2. 下载 Windows 64 位 MSI 安装包，例如：
   - 推荐同主版本补丁版：`go1.26.x.windows-amd64.msi`
   - 如老师要求完全一致，可找历史版本：`go1.26.1.windows-amd64.msi`
3. 双击 MSI 安装，默认安装到：

```text
C:\Program Files\Go
```

4. 重新打开 PowerShell，检查：

```powershell
go version
go env GOPATH
```

5. 国内网络建议配置 Go 代理：

```powershell
go env -w GOPROXY=https://goproxy.cn,direct
go env -w GOSUMDB=sum.golang.google.cn
```

如果后续下载依赖失败，可以临时改回：

```powershell
go env -w GOPROXY=https://proxy.golang.org,direct
go env -w GOSUMDB=sum.golang.org
```

## 三、安装 MySQL

1. 打开 [MySQL Installer 官方下载页](https://dev.mysql.com/downloads/installer/)。
2. 下载 Windows 版 MySQL Installer。
3. 安装时至少选择：
   - MySQL Server 8.0.x
   - MySQL Workbench，可选但建议安装
   - MySQL Shell，可选
4. 端口保持默认：

```text
3306
```

5. root 密码有两种处理方式，二选一：
   - 简单方式：安装时把 root 密码设置为 `123456`，与项目配置一致。
   - 推荐方式：使用自己的 root 密码，然后修改 `code/go/configs/dev/config.yaml` 中的 `Database.Password`。

后端当前数据库配置在：

```text
E:\项目\Go-区块链\中药房中药材溯源系统\code\go\configs\dev\config.yaml
```

关键配置如下：

```yaml
Database:
  DBType: mysql
  UserName: root
  Password: 123456
  Host: 127.0.0.1:3306
  DBName: hgy
  TablePrefix: oh_
```

## 四、初始化数据库

项目 SQL 文件有两个：

```text
E:\项目\Go-区块链\中药房中药材溯源系统\code\go\oh-admin.sql
E:\项目\Go-区块链\中药房中药材溯源系统\code\go\inspection_record.sql
```

注意：SQL 文件注释里写过源库名 `oh-admin`，但当前后端配置实际连接的是 `hgy`，因此本机建议创建并导入到 `hgy`。

### 方式一：使用 MySQL Workbench 导入

1. 打开 MySQL Workbench，连接本机 MySQL。
2. 执行：

```sql
CREATE DATABASE IF NOT EXISTS hgy DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE hgy;
```

3. 依次打开并执行：
   - `code/go/oh-admin.sql`
   - `code/go/inspection_record.sql`

### 方式二：使用 MySQL 命令行导入

打开 PowerShell，进入 MySQL 客户端：

```powershell
mysql --default-character-set=utf8mb4 -uroot -p
```

输入 root 密码后，在 MySQL 里执行：

```sql
CREATE DATABASE IF NOT EXISTS hgy DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE hgy;
SOURCE E:/项目/Go-区块链/中药房中药材溯源系统/code/go/oh-admin.sql;
SOURCE E:/项目/Go-区块链/中药房中药材溯源系统/code/go/inspection_record.sql;
```

导入后检查：

```sql
USE hgy;
SHOW TABLES;
SELECT username, realname FROM oh_admin_user;
```

## 五、安装 Node.js 和 npm

1. 打开 [Node.js 官方下载页](https://nodejs.org/en/download)。
2. 下载 Windows Installer。
3. 安装完成后重新打开 PowerShell，检查：

```powershell
node -v
npm -v
```

4. 国内网络建议设置 npm 镜像：

```powershell
npm.cmd config set registry https://registry.npmmirror.com
```

说明：Windows PowerShell 有时会因为执行策略拦截 `npm`，本项目命令建议统一使用 `npm.cmd`。

## 六、安装 Git

1. 打开 [Git for Windows](https://git-scm.com/install/windows)。
2. 默认安装即可。
3. 检查：

```powershell
git --version
```

## 八、常见问题

### 1. `go` 不是内部或外部命令

原因：Go 没有安装成功，或 PATH 没刷新。

处理：

1. 重新打开 PowerShell。
2. 确认 `C:\Program Files\Go\bin` 已加入系统 PATH。
3. 再执行 `go version`。

### 2. `Access denied for user 'root'@'localhost'`

原因：`code/go/configs/dev/config.yaml` 里的 MySQL 用户名或密码与本机不一致。

处理：修改：

```yaml
Database:
  UserName: root
  Password: 你的本机密码
```

### 3. `Unknown database 'hgy'`

原因：没有创建项目配置里的数据库。

处理：

```sql
CREATE DATABASE IF NOT EXISTS hgy DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

然后重新导入两个 SQL 文件。

### 4. npm 安装慢或失败

先设置镜像：

```powershell
npm.cmd config set registry https://registry.npmmirror.com
```

再重新执行：

```powershell
npm.cmd install
```

### 5. `dapingzhanshi` 报 OpenSSL 或 `ERR_OSSL_EVP_UNSUPPORTED`

这是旧版 Vue CLI 4 / Webpack 4 在较新 Node.js 上常见的问题。当前 PowerShell 窗口先执行：

```powershell
$env:NODE_OPTIONS="--openssl-legacy-provider"
npm.cmd run serve
```

如果仍失败，可安装 nvm-windows 后给旧大屏项目单独切换到 Node 16。

### 6. 端口被占用

后端默认端口是 `9090`。检查端口：

```powershell
Get-NetTCPConnection -LocalPort 9090
```

也可以临时换端口启动：

```powershell
cd E:\项目\Go-区块链\中药房中药材溯源系统\code\go
go run main.go -port 9091
```

如果后端端口改成 `9091`，大屏的接口地址也要同步改为新的后端端口：

```text
code\dapingzhanshi\src\api\http.js
```
