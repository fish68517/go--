# 简单运行说明书

本文档默认已经完成：

- Go、MySQL、Node.js、Git 安装
- MySQL 已创建 `hgy` 数据库
- 已导入 `code/go/oh-admin.sql` 和 `code/go/inspection_record.sql`
- `code/go/configs/dev/config.yaml` 中的数据库账号密码与本机一致

## 一、项目组成

| 目录 | 作用 | 默认端口 |
| --- | --- | --- |
| `code/go` | Go + Gin 后端，包含后台管理页面、接口、数据库访问、上链接口调用 | `9090` |
| `code/dapingzhanshi` | Vue 2 大屏展示，接口默认请求 Go 后端 | Vue CLI 默认 `8080` |
| `code/vue` | Vue 3 + Vite 前端页面 | `5178` |

大屏接口写在：

```text
E:\项目\Go-区块链\中药房中药材溯源系统\code\dapingzhanshi\src\api\http.js
```

当前请求地址是：

```text
http://127.0.0.1:9090/buss/bigscreen
```

所以运行大屏前，必须先启动 Go 后端。

## 二、启动顺序

推荐顺序：

1. 启动 MySQL。
2. 启动 Go 后端。
3. 启动 `dapingzhanshi` 大屏。
4. 如需要，再启动 `code/vue` 前端。

## 三、启动 Go 后端

打开 PowerShell：

```powershell
cd E:\项目\Go-区块链\中药房中药材溯源系统\code\go
go mod tidy
go run main.go
```

看到程序没有退出，说明后端已经在运行。浏览器打开：

```text
http://127.0.0.1:9090/login
```

默认管理员账号：

| 用户名 | 密码 |
| --- | --- |
| `admin` | `123456` |

如果登录失败，优先检查：

- MySQL 是否已启动
- `hgy` 数据库是否已导入 SQL
- `code/go/configs/dev/config.yaml` 里的 MySQL 密码是否正确

## 四、启动大屏 `dapingzhanshi`

新开一个 PowerShell，不要关闭后端窗口：

```powershell
cd E:\项目\Go-区块链\中药房中药材溯源系统\code\dapingzhanshi
npm.cmd install
npm.cmd run serve
```

Vue CLI 默认访问地址通常是：

```text
http://localhost:8080/
```

如果终端提示端口不是 `8080`，以终端输出的地址为准。

大屏页面需要 Go 后端 `9090` 正常运行，否则页面接口会请求失败。

## 五、启动 Vue 前端 `code/vue`

如需要运行 Vue 3 前端，新开一个 PowerShell：

```powershell
cd E:\项目\Go-区块链\中药房中药材溯源系统\code\vue
npm.cmd install
npm.cmd run dev
```

浏览器打开：

```text
http://127.0.0.1:5178/
```

说明：该前端的 Vite 配置里 `/api` 代理当前指向外部区块链服务：

```text
http://116.198.196.57:9000
```

如果本机网络无法访问该地址，相关接口页面会失败，但不影响 Go 后端和后台管理页面运行。

## 六、快速检查接口

后端启动后，可以在浏览器检查：

```text
http://127.0.0.1:9090/check
```

大屏接口检查：

```text
http://127.0.0.1:9090/buss/bigscreen/bigScreenData/getLatestScreenData
```

如果大屏接口返回 JSON，说明大屏和后端连接基础正常。

## 七、后台功能简单验证

1. 打开 `http://127.0.0.1:9090/login`。
2. 使用 `admin / 123456` 登录。
3. 进入处方相关菜单，查看接方、审方、处方查询、煎药过程数据上链等页面是否能打开。
4. 进入大屏页面，确认统计数据能展示。

注意：

- 上链功能会请求外部服务 `http://116.198.196.57:9000`。如果网络不通，上链会失败，但不代表本机后端没有启动成功。
- 处方扫描页面不是普通菜单权限判断，而是按业务角色判断。若提示“无扫描业务权限”，需要使用调剂员、复核员、泡药员、煎药员、包装员、发货员等业务角色账号，或给当前账号分配对应角色。

## 八、停止项目

每个运行中的 PowerShell 窗口按：

```text
Ctrl + C
```

依次停止：

1. `code/vue`
2. `code/dapingzhanshi`
3. `code/go`

MySQL 服务可以保持运行。

## 十、排错顺序

遇到无法运行时，按这个顺序排查：

1. `go version`、`node -v`、`npm -v`、`mysql --version` 是否能正常输出。
2. MySQL 是否已启动。
3. `hgy` 数据库是否存在，表是否导入成功。
4. 后端 `go run main.go` 是否一直运行，没有报数据库连接错误。
5. 浏览器是否能打开 `http://127.0.0.1:9090/login`。
6. 大屏是否在后端启动后再运行。
7. 如果端口冲突，先换端口或关闭占用端口的程序。
