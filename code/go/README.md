

## 📚 项目介绍
智慧中药房系统的建设旨在解决传统中药房面临的这些问题，实现中药房业务的智能化管理。它借助人工智能、物联网等先进技术，对中药房的库存、处方审核、药品调配、煎药、配送等全流程进行全面监控和优化。
通过智能化审方系统，可自动校验处方，精准识别异常处方，提高处方审核的准确性和效率，借助物联网智能煎药机，精确控制煎药的加水、温度和时间，确保中药煎制的质量和疗效；同时，通过信息化管理平台，
实现各环节信息的实时共享和高效传递，提高患者取药的便捷性和服务满意度.

## 🍪 内置模块
+ 用户管理：用于维护管理系统的用户，常规信息的维护与账号设置。
+ 角色管理：角色菜单管理与权限分配、设置角色所拥有的菜单权限。
+ 菜单管理：配置系统菜单，操作权限，按钮权限标识等。

## 🍪 项目结构

```
├── configs         // 系统配置
├── global          // 系统全局变量

│   ├── dao         // DAO层
│   ├── middleware  // 中间件
│   ├── dto         // DTO层
│   ├── handler     // 控制器层
│   ├── model       // 模型层
│   ├── routers     // 路由
│   ├── vo          // VO层
│   ├── widget      // 组件层
│   └── service     // 服务层

├── pkg             // 工具包
├── storage         // 日志存储目录
```
